# market-radar/requirements.txt
# Unified venv for Market Radar + Reports news integration
#
# ARCHITECTURE NOTE — read before modifying:
# This venv serves market-radar/ as the host application for the unified news app.
# It intentionally merges market-radar/ and reports/ dependencies only.
#
# signal/ (torch, transformers, spacy, psycopg2, fastapi) is EXCLUDED by design:
#   - torch alone is ~2GB and has Python version constraints
#   - fastapi conflicts with flask in the same environment
#   - signal/ runs as a separate process with its own venv
#   - signal enrichment (FinBERT sentiment) is accessed via optional HTTP call
#     to http://localhost:8000 — graceful no-op if signal server is not running
#
# Future integrations that belong in THIS venv:
#   - market-radar/backend/news/feed_adapters.py (imports from reports/ via sys.path)
#   - market-radar/backend/news/feed_aggregator.py (merges articles + events + market data)
#   - market-radar/backend/news/digest_generator.py (llm journalist layer)
#   - market-radar/backend/news/news_routes.py (flask blueprint: /api/feed, /api/digest)
#   - APNs push notification sender (ios app backend)
#
# Install: pip install -r requirements.txt
# After install, also run: playwright install chromium
#
